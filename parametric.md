# 🟠 Parametric Primitive Representations (Sec. 4)

Primitive methods organize fitted state as a variable-size collection of spatially addressable local elements (e.g., Gaussians) and reconstruct by projection, aggregation, splatting or rasterization. Primitive count and memory are compaction proxies, estimated entropy is a rate surrogate, and only serialized bits including all side information define operational rate.
