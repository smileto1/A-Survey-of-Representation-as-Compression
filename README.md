## 🧭 Scope and Taxonomy

**Instance-Fitted Representation Compression**: an encoding process belongs to this paradigm when fitting a representation state to the target instance *constitutes* the encoding process and reconstruction instantiates or evaluates that fitted state. A fitted state serves as a coded description only when its stored parameters and all decoder-required side information are specified and rate-accounted; representation precursors without a decodable payload remain in scope as substrates. Latent or coding-decision refinement inside an otherwise intact amortized or conventional codec is treated only as context. The reviewed literature covers 2D images, video, static and dynamic 3D scenes, and scientific or biomedical volumes; audio and text are outside the present scope.

The survey organizes the literature through a **two-route taxonomy** determined by the terminal reconstruction substrate and operator:

| Route | Fitted state | Terminal operator | Representative instances |
| --- | --- | --- | --- |
| **Functional Representations** | neural weights, modulations, latents, grids, tensors, hash features | query evaluation, interpolation, integration | SIREN, NeRF, COIN, NeRV, COOL-CHIC, NVRC |
| **Parametric Primitive Representations** | a finite set of spatially addressable local elements (e.g. Gaussians) | projection, aggregation, splatting, rasterization | 3DGS, GaussianImage, HAC, 4D-GS, GSVC, 4DGC |

Hybrid designs stay inside the route of their terminal operator and only receive a secondary *Functional-hybrid* / *Primitive-hybrid* tag; *Cross-route hybrid* is reserved for systems with two genuine terminal operators. Within each modality bucket, the paper groups methods by three analytical stages, and this list keeps the same headings:

- **Capacity** — Representation Capacity Improvement: mechanisms that mainly shape distortion or computation (encodings, activations, hierarchies, initialization, density control).
- **Rate Optimization** — payload reduction: pruning, factorization, quantization, dictionaries / codebooks, structure or context modeling, bitstream formation.
- **RD Optimization** — Rate–Distortion Optimization: an explicit differentiable rate term during fitting (D + λ·R̂).

> **Evidence boundary used throughout the survey.** Parameter count, primitive count, memory, checkpoint size, estimated entropy and serialized bits are *distinct* measures. A fitted representation becomes a coded payload only when its stored state and every decoder-required side information are specified and rate-accounted. Tags in this repository describe the *mechanism* each paper contributes as discussed in the survey; they do not rank methods.

Literature coverage was closed in **August 2026**. Every work cited in the manuscript is listed below. A paper appears under every heading in which the survey discusses it, so some works are listed more than once with different mechanism tags.

## 🔵 Functional Representations (Sec. 3)

Functional methods fit a query-conditioned observation operator and reconstruct by evaluating, interpolating or integrating a function- or field-like state (weights, modulations, latents, grids, tensors, hash features). The fitted state need not be the whole compressed object: a payload may combine weights, latents, grids, codebooks, masks and side information; the survey reserves the term codec for methods that specify a decodable serialization, all decoder-required state and complete payload accounting.

## 🟠 Parametric Primitive Representations (Sec. 4)

Primitive methods organize fitted state as a variable-size collection of spatially addressable local elements (e.g., Gaussians) and reconstruct by projection, aggregation, splatting or rasterization. Primitive count and memory are compaction proxies, estimated entropy is a rate surrogate, and only serialized bits including all side information define operational rate.
